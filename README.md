# PortFolio Paco Canovaca

## Tecnologías utilizadas
- React.js
- Tailwind CSS

## Planteamiento
La idea es crear una página SPA (Single Page Application), es decir, que cada apartado y sección vaya cargando en la misma página en lugar de generar una página nueva para ello. Además, no quiero hacer el típico diseño en el que todo está presente en la página de arriba abajo (Hero, proyectos, experiencia, estudios…), sino que va a haber un menú de navegación y cada botón, según se vaya seleccionando, desplegará el contenedor de React correspondiente a su contenido.
